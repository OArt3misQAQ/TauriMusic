免费上限，不做付费解锁

音质固定取平台给匿名听众的免费上限，不提供会员绕过。VIP、付费或版权受限曲目会明确提示，不试探付费文件。

从试听，到真正收藏

保存时复用本地导入管线：写入标签与内嵌封面、回写同名 LRC，再按 SHA-256 内容指纹判重，重复保存不会堆积副本。

在线搜索、取链、歌词与封面请求均由 Rust 端完成；播放与封面只走对应平台官方 HTTPS 域名。音频内容不会被上传。

FEATURES · 核心体验

日常听歌需要的，都认真做好了

从第一次导入，到播放、整理、备份与迁移，每一步都有完整闭环。

曲库整理与全格式导入

递归扫描、增量合并，自动识别标签、封面与文件名。常见格式直接播放；APE、WMA、DSF 等经内置 ffmpeg 并行转为 FLAC，原文件不动。

双语歌词，逐行同步

内嵌歌词与同名 LRC 都能识别，老文件乱码自动修复。在线匹配可补官方中文译配，播放页逐行滚动，点击任一句直接跳转。

桌面歌词，不被底板束缚

透明小窗直接浮在壁纸之上，显示当前句、译文与下一句。颜色和三档字号可调，进度线支持点击或拖动跳转，位置与尺寸自动记忆。

看得见的随机播放队列

切入随机时队列真实重排，本轮顺序在抽屉里一目了然；同专辑尽量不连播。「上一曲」回到实际播放历史，而不是机械地按列表后退。

整个曲库，可以搬去新位置

main 分支新增：设置中选择新目录，即可迁移音乐、曲库数据、封面与回收站。先复制并校验，再重映射路径和重启；中途失败会保留旧库，也可一键迁回默认位置。

大曲库与性能模式

歌曲、歌单详情和播放队列采用虚拟滚动；批量导入并行转码，无新文件时跳过全库重扫。「流畅 / 精致」两档性能模式，Windows 与 Android 都可选择。

删除之前，留一次反悔机会

单曲与整张专辑删除后先进入应用内回收站，音频和歌词保留 30 天。随时可以还原到原位置，确认不要后再彻底清除。

播放之外，也融入系统

Windows 托盘常驻、迷你黑胶控制面板、系统媒体控制与全局快捷键协同工作。关闭主窗口音乐不中断，锁屏与音量面板也能控制播放。

歌单与音乐，都能打包带走

单曲、整张专辑或完整歌单都能导出为标准 7z 音乐包。导入先预览并逐文件校验，封面、歌词、双语译配与歌单顺序一起还原。

ANDROID · 原生手机界面

从电脑桌面，到日常口袋

Android 不是桌面界面的缩小版。底部「在线 / 资料库 / 我的」三 Tab、常驻迷你播放条、全屏播放器与触屏操作卡片，都是为手机重新组织。

  • 系统分享即导入在其他 App 里选择「分享」或「用 TauriMusic 打开」，音频自动入库并直接播放。
  • 四音源与本地统计同源在线搜索、试听、保存与桌面端共享同一套核心能力。
  • 流畅优先，也可切换精致手机默认减少重模糊与氛围特效；安全区、返回键和系统栏明暗均已适配。

Android 端不提供主动文件夹扫描；本地曲目通过系统分享进入。公开发布签名 arm64 APK，可侧载并覆盖升级。

逐文件 SHA-256 校验

打包时记录内容指纹，导入时再次验证。传输损坏会在入库前被拦截，相同歌曲重复导入则自动跳过。

FAQ · 常见问题

下载前，你可能还想知道

本地音频和听歌统计会被上传吗？

不会。本地播放始终读取你的文件，统计只保存在设备上的 stats.json。联网仅用于在线搜索、免费曲目试听，以及你主动发起的歌词、封面匹配或在线保存。

在线音乐可以听 VIP 或付费歌曲吗？

不提供任何付费解锁、登录态绕过或签名绕过。只播放平台公开接口向匿名听众开放的免费曲目；受限曲目会提示并跳过。

迁移存储位置会立刻删除旧文件吗？

不会直接切换。桌面端先完整复制并校验，再重映射曲库路径、写入引导文件并重启；全部成功后才清理旧位置。中途失败会保留旧库，个别被占用文件会跳过并提示。

有 macOS、Linux 或 iOS 版本吗？

当前公开构建覆盖 Windows 与 Android arm64。macOS / iOS 需要 macOS 与 Xcode 工具链，目前没有对应的公开安装包；iOS 液态玻璃是本页及应用的视觉设计语言，不代表已有 iOS 客户端。
