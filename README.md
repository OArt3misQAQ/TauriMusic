# TauriMusic

参考 Apple Music 设计语言的本地音乐播放器,基于 **Rust + Tauri 2 + Vue 3** 构建,并内置网易云 / QQ 音乐 / 酷狗音乐 / 酷我音乐免费曲目在线试听。

![TauriMusic](https://img.shields.io/badge/Tauri-2-24C8D8) ![Rust](https://img.shields.io/badge/Rust-stable-DEA584) ![Vue](https://img.shields.io/badge/Vue-3-42B883)

## 功能特性

- **曲库扫描**:递归扫描指定的音乐文件夹,增量合并(文件未变化时跳过解析),扫描进度实时显示;导入目录顶层的散装音频自动按「艺人\专辑」归位
- **元数据识别**:标题 / 艺人 / 专辑 / 专辑艺人 / 曲目号 / 年份 / 流派 / 时长,标签缺失时回退到 "艺人 - 标题" 文件名解析
- **封面识别**:优先提取内嵌封面(同一专辑只落盘一次),其次读取目录内的 `cover.*` / `folder.*` / `front.*` / `album.*` 图片
- **歌词识别**:
  - 内嵌歌词标签(ID3v2 USLT、Vorbis Comments `LYRICS` 等)
  - 同名 `.lrc` 伴生文件
  - 自动处理 GBK / GB18030 / UTF-16 编码的 LRC 文件,以及 "GBK 内容被标记为 Latin-1" 的乱码
  - 全屏播放页支持**逐行同步滚动**的歌词,点击歌词行跳转播放位置
  - **中英对照双语歌词**:在线匹配自动抓取官方译配(网易云 `tlyric`,LRCLIB 译文兜底),原文句下小字显示中文译文,播放页与桌面歌词小窗同步生效;已有英文歌词的曲目重新点「在线匹配」可只补译文(不替换原文),.tmc/.tmcl 音乐包导出导入全程携带双语
- **播放**:底部播放条 + 全屏播放页,顺序播放 / 列表循环 / 单曲循环 / 随机播放四态互斥(模式持久化);随机采用**可见洗牌队列**——切入随机或点各列表「随机播放」时队列真实重排(正在播的提到队首),播放页队列抽屉即时显示洗好的顺序,每次切入随机都重新洗牌,随机范围内同专辑不连播;"上一曲"回到**实际播放历史**的上一首;歌曲页提供"随机播放全部"全库随机入口,切换播放模式时浮出模式名气泡提示。全屏播放页顶栏只留歌框与音量(传输控件动画收起,歌框居中并随切歌滑动过渡),新增**播放队列**抽屉——按本轮循环的真实播放顺序列曲,点行即切歌、悬停可移除(不删文件)
- **全局快捷键**:空格 播放/暂停 · ←/→ 快退/快进 · Ctrl+←/→ 切歌 · ↑/↓ 音量 · M 静音 · Esc 关播放页(输入框聚焦时自动让位)
- **浏览视图**:专辑(网格)、艺人(列表 + 详情)、歌曲、全文搜索(歌曲 / 专辑 / 艺人);歌曲列表虚拟滚动,万首曲目依然流畅
- **批量操作**:歌曲列表 Ctrl/Shift 多选 + 浮动操作条(播放 / 批量导出 / 批量删除),整张专辑一键导出
- **删除与应用内回收站**:单曲与整张专辑删除,音频与歌词移入应用内回收站(保留 30 天自动清理),删除前两段确认防误触;侧边栏回收站随时还原或彻底删除,防止误删无法找回
- **在线音乐试听(四音源)**:侧边栏「在线音乐」入口——可切换 网易云 / QQ 音乐 / 酷狗音乐 / 酷我音乐,关键词搜索单曲、分页加载;免费曲目点击即播,播放直链**懒取**(进队列不请求、真正开播才取并缓存,避免链接过期),播放页/氛围背景/托盘唱机/SMTC 同步显示在线封面;VIP/需购买/版权受限曲目不做任何解锁,置灰提示并自动跳下一曲。搜索、取链与歌词/封面抓取全部在 Rust 端完成(前端 CSP 不直连外网);在线曲目 id 以 `net:` / `qq:` / `kugou:` / `kuwo:` 前缀与本地路径 hash 空间隔离,不入曲库持久化。播放直链与封面图在交给 WebView 前都经过对应平台官方 https 域名白名单校验,CSP 也只放行这些域名;酷我接口对 VIP 也会返回直链,因此只允许本次会话搜索结果中 `PAY=0` 的曲目取链。QQ/酷狗提供在线歌词与封面,酷我首版仅播放(封面占位、无歌词)
- **在线音质**:固定取各平台**免费给到匿名听众的上限**,页面不设档位选择——网易云 `br=320000`(该曲没有 320k 源时接口自动降级)、酷狗优先走搜索结果里的 `HQFileHash`(320k,且仅 `HQPrivilege` 判免费才用),QQ 与酷我匿名最高就是 128k,按 128k 取,不去试探任何付费文件。酷狗 HQ 被接口拒绝时自动回落 128k,高音质是上限而非硬性条件
- **在线曲目保存到本地库**:免费曲目行尾「下载」按钮把正在试听的那份文件存进导入目录——取链(与播放同一道闸)、下载、写入标题/艺人/专辑标签与内嵌封面、同名 `.lrc` 旁路歌词,再复用既有散装导入管线完成复制归位、全量扫描与 SHA-256 内容指纹判重(反复保存同一首不会堆重复文件),入库后与本地曲目完全同级。容器扩展名按直链推导(mp3/m4a/flac),标签写入失败不致命,文件名「艺人 - 标题」仍可被扫描器解析
- **听歌统计(本地/在线分域)**:统计页可切换「本地 / 在线」两套口径,各自展示总览(累计/今日/本周时长、播放次数、歌曲数)、最近 30 天柱状图、最常听歌手/专辑/歌曲榜与最近播放;按「听满半曲或 4 分钟」计一次播放。设置 → 统计与隐私提供总开关——关闭后**停止收集并隐藏统计页**;数据仅保存在本机 `stats.json`,**绝不联网上传**,可一键清除
- **深浅色外观**:默认跟随系统,可手动切换
- **液态玻璃外观**:专辑封面驱动的氛围背景(深度模糊 + 缓慢漂移、随曲目切换淡入淡出),停靠式磨砂玻璃面板(边缘透镜折射 + 跟随光标流动的高光),可一键开关
- **TMC 音乐包**:`.tmc` = 标准 7z 包(音频 + 同名 LRC + 封面 + meta.json),支持双击导入 / 拖拽导入 / 一键导出,文件关联开箱即用
- **音乐包导入预览**:双击 / 拖入 / 设置页导入 `.tmc/.tmca/.tmcl` 时,主窗口弹出**导入预览**——先解包到暂存解析包内曲目(封面、歌名、艺人、专辑、时长),可勾选后确认写入;导入完成列出**本次实际导入的歌曲**;内容级去重:音频 SHA-256 与曲库已有曲目相同(单曲包同样生效)自动跳过,不产生重复
- **专辑包(TMCA)**:`.tmca` = 单文件整张专辑(7z 存储模式打包,接近拷贝速度),双击 / 拖拽 / 设置页导入即整张入库,专辑归类由元数据自动成立
- **播放列表(歌单)**:自由创建 / 重命名 / 删除多个歌单,歌曲行右键、多选操作条、专辑右键均可加入歌单;详情页支持播放 / 随机播放 / 曲目排序 / 移除;导出为 **TMCL**(`.tmcl` = 标准 7z:整单音乐源文件 + 歌词 + 封面 + meta.json + `playlist.json`),双击 / 拖拽 / 设置页导入即还原歌单
- **直接导入音乐文件**:设置页多选音频文件(或拖入窗口),自动通过公开接口匹配封面与歌词(多源兜底)
- **在线元数据补全**:专辑详情页 / 歌曲页一键补全缺失封面与歌词——封面走 网易云 → iTunes → 酷我,歌词走 网易云 → LRCLIB → 酷我 三级兜底(仅元数据,播放始终走本地文件);歌词选曲按 **现场版识别**(Live/现场/演唱会/实况)优先返回现场版歌词,辅以本地时长比对纠出版本,避免演唱会版错配录音室时间轴
- **首次启动引导**:使用声明 → 感谢信 → 初始设置三步式欢迎流程;初始设置含开机自启动与音乐包文件关联复选框(默认全部不勾选,由用户决定)
- **托盘常驻与迷你播放面板**:关闭窗口最小化到托盘,音乐不中断;托盘左键唤起主窗口;右键在图标上方弹出**迷你黑胶唱机**——封面做成旋转唱片(播放时转、暂停定格,与「墨夜胶片」图标同一语言),带铭牌行、呼吸灯、唱针进度点与播放/上下曲控制,失焦自动隐藏
- **启动守卫**:再次启动时若检测到已有实例在运行,会询问是否结束旧进程并重启(旧实例卡死时的一键自救);连点/启动竞态下**只会弹一次询问窗**,其余启动自动让位并唤起已有窗口;双击音乐包导入不打扰
- **系统媒体控制(SMTC)**:Windows 音量弹窗、锁屏与控制中心显示 TauriMusic 的曲名、歌手与专辑封面,可直接控制播放/暂停/上下曲
- **桌面歌词小窗**:设置 → 外观一键开启——桌面置顶的独立小窗,「沉浸文字」设计:窗口全透明,歌词大字浮于桌面(当前句品牌色渐变填充+细进度线,下一句小字预告),文字下贴可调**烟熏背景板**(不透明度与字号缩放均可调),悬停浮现控制胶囊(歌曲名 + 播放/切歌/音量);任意拖动(位置自动记忆)与窗口拉伸,关闭主窗口音乐不中断
- **关于页**:实时显示主进程内存与 CPU 占用;内附一封作者的感谢信(信纸样式,跟随深浅色与皮肤)

## 支持的格式

直放:`mp3` `m4a` `flac` `ogg` `opus` `wav`(播放由系统 WebView2 解码器承担;m4a 内的 ALAC 无损同样可播)

**全格式导入(ffmpeg 转码)**:`ape` `wma` `wv` `tta` `tak` `dsf` `dff` `ac3` `mka` `aif/aiff` `mpc`——导入(拖拽/文件选择/双击打开)时自动经内置 ffmpeg 转为无损 FLAC 入库,**原文件保持不动**;转码件保留元数据与内嵌封面。安装包已内置 ffmpeg.exe;缺失时(部分开发环境)也可使用系统 PATH 中的 ffmpeg,都没有则跳过此类文件。注意:转码发生在"导入"动作;以"添加文件夹"方式登记的外部目录不转码,其中的非常规格式不会被扫描。

音乐包/播放列表/专辑容器:`.tmc`(单曲包)、`.tmcl`(歌单包)、`.tmca`(专辑包),均为标准 7z,可用任意解压工具查看。
打包时逐文件记录 SHA-256(存于 meta.json / playlist.json / album.json,与打包同遍读盘完成),导入时逐文件校验——传输损坏在入库前即被拦截;曲目哈希同时用作内容指纹,音乐包与散装导入互相去重,相同歌曲重复导入自动跳过。

## 开发

```bash
npm install        # 安装前端依赖
npm run tauri dev  # 开发模式运行
```

要求:Node.js ≥ 20.19、Rust stable、WebView2(Windows 11 自带)。

## 构建

```bash
npm run tauri build             # 产出安装包(msi / nsis)
npm run tauri build -- --no-bundle  # 仅产出绿色版 exe
```

产物位于 `src-tauri/target/release/tauri-music.exe`。推送 `v*` tag 到 GitHub 会自动构建安装包并发布 Release。

## 测试与代码质量

```bash
cd src-tauri
cargo test                        # Rust 单元测试
cargo clippy --all-targets -- -D warnings   # Rust 静态检查
cargo fmt --all --check           # 格式检查
```

```bash
npm run lint       # ESLint
npm run build      # vue-tsc 类型检查 + 构建
```

CI(Linux + Windows)在每次 push/PR 时运行上述全部检查;推 `v*` tag 自动发布安装包。

## 示例工具(可选)

```bash
cd src-tauri
cargo run --example make_fixture                        # 生成示例曲库到 test-music/
cargo run --example make_tmc                            # 生成 TMC 演示包到 demo/
cargo run --example make_tmc -- extract <包> <目录>      # 解包任意 .tmc(调试用)
cargo run --example make_tmc -- netease <标题> <艺人> [时长秒]  # 验证网易云匹配(现场版选曲)
cargo run --example make_beyond_tmc -- <输入目录> <输出目录> [过滤词]
                                                        # 批量把目录里的音频打包为 TMC,
                                                        # 元数据按文件名中的网易云 ID 自动补齐
```

```

  components/           #   顶栏、侧边栏、全屏播放页、曲目列表、弹窗、右键菜单等
  views/                #   专辑 / 专辑详情 / 艺人 / 歌曲 / 搜索 / 在线音乐 / 播放列表 / 歌单详情 / 听歌统计 / 回收站
src-tauri/
  src/scanner.rs        #   曲库扫描与元数据解析(lofty)
  src/lyrics.rs         #   LRC 解析与编码修复
  src/online.rs         #   网易云/QQ/酷狗/酷我公开接口(搜索/取链/歌词/封面)与来源域名白名单
  src/model.rs          #   数据模型与 library.json 持久化(原子写 + 备份恢复)

  src/import.rs         #   散装导入:复制进导入目录、ffmpeg 转码与内容指纹去重
  src/enrich.rs         #   在线元数据补全编排(封面/歌词多级兜底匹配)与在线下载入库
  src/trash.rs          #   应用内回收站:移入/还原/彻底清除/超期自动清理
  src/playlists.rs      #   用户歌单 CRUD 实现与条目快照/命名助手
  src/assoc.rs          #   文件关联与开机自启动(HKCU 注册表,用户级)
  src/media.rs          #   系统媒体控制(SMTC)+ 托盘播放控制菜单
  examples/make_fixture.rs      # 示例曲库生成器
  examples/make_tmc.rs          # TMC 演示包生成 + 解包/网易云调试工具

demo/                   # TMC / TMCA 演示包(make_tmc 生成)
design/                 # 应用图标 SVG 源稿(手绘几何,零素材引用);改后用 npx tauri icon 重新生成全套

TauriMusic-promo/       # 宣传素材
```

## 数据存储

- 曲库、文件夹配置、播放列表与应用内回收站:`%APPDATA%\com.art3mis.taurimusic\library.json`(写入为原子替换,旧文件保留为 `library.json.bak`)
- 听歌统计:`%APPDATA%\com.art3mis.taurimusic\stats.json`(同样原子写 + `.bak` 备份;仅本机,零联网,统计总开关在设置 → 统计与隐私;v2 结构按本地/在线分桶并保存在线曲目元数据)
- 回收站文件本体:`%APPDATA%\com.art3mis.taurimusic\Trash\`(删除的音乐移到这里,30 天后启动时自动清理)
- 封面缓存:`%LOCALAPPDATA%\com.art3mis.taurimusic\covers\`(本地 256px 列表图 + 512px 详情图两级缩略图,列表场景解码内存降至 1/4;在线曲目封面落在 `covers/online/{来源}_{平台id}.jpg`,网易云沿用 `{平台id}.jpg`;每次扫描自动清理已删音乐残留的孤儿缩略图)

删除这两个目录即可完全重置应用。
